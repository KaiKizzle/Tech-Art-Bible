    Hair: Strands and Cards

    Hair is thousands of thin, overlapping cylinders. This unit covers how games fake them with cards, shade them along the strand instead of the normal, place the two highlights, and handle the alpha.

    Builds on PBR shading and Transparency. Engine notes cover Unity HDRP, Unity URP and Unreal.

    Strands or cards

    A human head has about 100 000 hairs. Film renders every one as a curve; games mostly cannot. The standard real-time solution is : strips of a few quads, each textured with an image of many hairs and their alpha (transparency). A full head takes a few hundred to a few thousand cards. Compare the geometry:

    Geometry is not the only cost. Cards overlap in many layers, and every layer runs the hair shader (overdraw):

    Strand rendering in real time exists (Unreal's groom system, compute rasterizers), but it remains a high-end option for close-up characters. This unit focuses on cards; the shading model is the same for both.

    Shading along the strand

    A hair is a thin cylinder. Its surface normal points every way around the strand, so a single normal per pixel makes no sense. What is well defined is the strand's direction, its T. Hair shading models use T instead of N. Kajiya and Kay's diffuse term is the light a cylinder receives from L, averaged around it, which works out as the sine of the angle between T and L:

    Light along the strand gives almost nothing (you see the hair end-on); light across it gives full brightness. On cards, T comes from the direction of the texture's V axis, or from a flow map that stores the strand direction per texel, transformed into world space with the tangent frame.

    The highlight band

    The specular highlight of a cylinder is not a dot but a line across it, wherever the strand runs perpendicular to the half vector. Kajiya–Kay specular measures exactly that, raised to a power for sharpness. Along a head, the strand direction turns, and the highlight forms the familiar band:

    // Kajiya–Kay specular with the usual directional fade
float StrandSpecular(float3 T, float3 V, float3 L, float exponent)
{
    float3 H = normalize(L + V);
    float  TdotH = dot(T, H);
    float  sinTH = sqrt(1 - TdotH * TdotH);
    float  dirAtten = smoothstep(-1, 0, TdotH);
    return dirAtten * pow(sinTH, exponent);
}

    Two shifted highlights

    Real hair shows two highlights. Light reflecting off the outer surface (R) gives a sharp, white one. Light entering the fibre, reflecting off its back and leaving again (TRT) gives a wider one tinted with the hair colour. Because the scales on a hair's surface are tilted, the two appear at slightly different places along the strand: R toward the root, TRT toward the tip (Marschner's measurements). Shaders reproduce that by tilting the tangent toward the normal by a different amount for each lobe:

    A noise texture added to the shift varies it per strand, which breaks the band into the streaky look of real hair. A third term from Marschner, TT (light passing straight through), makes backlit hair glow; it is usually added as a simple back-light term with the hair colour.

    Alpha, sorting and depth

    Hair cards combine every problem of transparency: thousands of overlapping layers in one mesh, which cannot be sorted per object. The common recipe has two passes:

    1. Opaque pass with alpha test at a high cutoff (0.5 to 0.9): the dense core of the hair, writing depth and receiving shadows.
    2. Blended pass for the soft, thin parts below the cutoff, drawn after it with depth testing against the first pass, so the wispy ends blend over a correct base.

    Alternatives are alpha to coverage with MSAA, and dithering with TAA, which is what most deferred renderers use. Sorting the cards inside the mesh from the scalp outward (in the modelling tool) helps the blended pass a lot.

    HDRP has a Hair material type in Shader Graph with a Kajiya–Kay approximation and a physically based Marschner model. Alpha Clipping, Transparent Depth Prepass/Postpass and Alpha to Mask cover the passes above.

    URP has no hair shader. Build Kajiya–Kay in Shader Graph with a Custom Function node (the code above), use Alpha Clipping for the opaque core and optionally a second transparent material on a duplicated mesh.

    Cards use the Hair shading model with Masked blend mode and dithered opacity; strands use the Groom system with its own rasterizer. The Hair shading model is a Marschner implementation with R, TT and TRT lobes.

    Root to tip, and self-shadowing

    Hair is darker near the scalp, both because roots are often darker and because the outer hair shadows the inner layers. Cards carry a gradient from root to tip in a UV channel or texture, used to darken the colour and the ambient light:

    For direct light, hair needs soft self-shadowing: a single shadow-map depth would make the outer layer shadow everything below completely. Engines estimate how much hair lies between a point and the light (deep opacity maps, or a thickness value from the shadow map) and attenuate exponentially, like light through skin.

    Build it in Unity HDRP

    HDRP's Hair graph implements the shading of this unit, including both shifted highlights. Most of the setup is the alpha recipe from Alpha, sorting and depth, plus sorting the cards inside the mesh, which the editor script does. Written for Unity 6 with HDRP 17; Unity 2022 LTS works the same apart from a few renamed menu entries.

    1. Create > Shader Graph > HDRP > Hair Shader Graph. Material type Approximate is the Kajiya–Kay model of this unit; Physical (Marschner, in recent versions) is more accurate and more expensive.
    2. Inputs: Base Color (root-to-tip gradient from the variation chapter), Hair Strand Direction (tangent space, default (0, −1, 0): down the card's V axis; feed a flow map decoded as (r·2 − 1, g·2 − 1, 0) for curls), Specular Tint and Specular Shift (R), Secondary Specular Tint and Secondary Specular Shift (TRT), Smoothness and Secondary Smoothness, Transmittance and Rim Transmission Intensity (TT).
    3. Alpha: tick Alpha Clipping for the opaque core. For soft ends, set Surface Type to Transparent with Transparent Depth Prepass and Postpass, which add the Alpha Clip Threshold Depth Prepass/Postpass blocks (0.8 and 0.2 are good starts). With TAA, dithered alpha is a cheaper alternative (Dither.hlsl).
    4. Put HairCardSorter.cs in an Editor folder, select the hair object and run Tools > Atlas > Sort Hair Cards Inside Out. GPUs draw the triangles of one draw call in index order, so inner cards now blend under outer ones.
    5. For URP or a custom look, use KajiyaKay.hlsl. In an Unlit graph, add a Custom Function node. Set Type to File, Source to KajiyaKay.hlsl and Name to KajiyaKay (without the _float suffix). Add the inputs TangentWS (Vector 3), NormalWS (Vector 3), ViewDir (Vector 3), LightDir (Vector 3), Shift1 (Float), Shift2 (Float), Exp1 (Float), Exp2 (Float), Noise (Float) and the outputs Diffuse (Float), Spec1 (Float), Spec2 (Float), in that order and with those types: they must match the function's parameters.
    #ifndef ATLAS_KAJIYA_KAY_INCLUDED
#define ATLAS_KAJIYA_KAY_INCLUDED

float StrandSpecular(float3 T, float3 H, float exponent)
{
    float TdotH = dot(T, H);
    float sinTH = sqrt(saturate(1.0 - TdotH * TdotH));
    return smoothstep(-1.0, 0.0, TdotH) * pow(sinTH, exponent);
}

// T: strand direction in world space. Noise (0..1, per strand) varies the shift.
void KajiyaKay_float(float3 TangentWS, float3 NormalWS, float3 ViewDir, float3 LightDir,
                     float Shift1, float Shift2, float Exp1, float Exp2, float Noise,
                     out float Diffuse, out float Spec1, out float Spec2)
{
    float3 T = normalize(TangentWS), N = normalize(NormalWS), L = normalize(LightDir);
    float3 H = normalize(L + normalize(ViewDir));
    float TdotL = dot(T, L);
    Diffuse = sqrt(saturate(1.0 - TdotL * TdotL)) * saturate(dot(N, L) * 0.5 + 0.5);   // sin(T, L), softened

    float n = Noise - 0.5;
    float3 T1 = normalize(T + N * (Shift1 + n * 0.3));      // primary (R): white, sharp
    float3 T2 = normalize(T + N * (Shift2 + n * 0.3));      // secondary (TRT): tinted, wider
    Spec1 = StrandSpecular(T1, H, Exp1);
    Spec2 = StrandSpecular(T2, H, Exp2);
}

#endif
    #if UNITY_EDITOR
using System.Linq;
using UnityEditor;
using UnityEngine;

// Reorders the triangles of the selected hair mesh from the centre outward, so inner cards draw first.
// Uses the mesh's bounds centre as the head centre; move it with "pivotOffset" if the head is offset.
public static class HairCardSorter
{
    static readonly Vector3 pivotOffset = Vector3.zero;

    [MenuItem("Tools/Atlas/Sort Hair Cards Inside Out")]
    static void Sort()
    {
        GameObject go = Selection.activeGameObject;
        if (go == null) return;
        var smr = go.GetComponent<SkinnedMeshRenderer>();
        var mf = go.GetComponent<MeshFilter>();
        Mesh src = smr != null ? smr.sharedMesh : mf != null ? mf.sharedMesh : null;
        if (src == null) { Debug.LogWarning("Select an object with a mesh"); return; }

        Mesh m = Object.Instantiate(src);
        m.name = src.name + "_Sorted";
        Vector3[] v = m.vertices;
        Vector3 pivot = m.bounds.center + pivotOffset;

        for (int s = 0; s < m.subMeshCount; s++)
        {
            int[] t = m.GetTriangles(s);
            int[] order = Enumerable.Range(0, t.Length / 3)
                .OrderBy(i => ((v[t[3 * i]] + v[t[3 * i + 1]] + v[t[3 * i + 2]]) / 3f - pivot).sqrMagnitude)
                .ToArray();
            var sorted = new int[t.Length];
            for (int k = 0; k < order.Length; k++)
            {
                sorted[3 * k] = t[3 * order[k]];
                sorted[3 * k + 1] = t[3 * order[k] + 1];
                sorted[3 * k + 2] = t[3 * order[k] + 2];
            }
            m.SetTriangles(sorted, s);
        }

        string path = AssetDatabase.GenerateUniqueAssetPath("Assets/" + m.name + ".asset");
        AssetDatabase.CreateAsset(m, path);
        if (smr != null) smr.sharedMesh = m; else mf.sharedMesh = m;
        Debug.Log("Saved " + path);
    }
}
#endif

Amplify Shader Editor: paste the function body into a Custom Expression node (mode Call with the file included, or Create with the code inline); inputs and outputs map the same way.

    URP has no hair shader: use the KajiyaKay function with GetMainLight(), Alpha Clipping for the core, and optionally a second, transparent material on a duplicate of the mesh for the soft ends.

    Cards: a material with Shading Model: Hair and Blend Mode: Masked (with Dither Opacity Mask for soft ends). Strands: the Groom system (Alembic import), rendered with its own rasterizer and deep shadows.
