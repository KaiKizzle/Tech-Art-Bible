    Build it in Unity HDRP

    Every unit ends with this chapter: how to build the technique in Unity HDRP, with the tools it needs, numbered steps and complete files to copy. Written for Unity 6 with HDRP 17; Unity 2022 LTS works the same apart from a few renamed menu entries.

    Shader GraphWhich graph type and material settings.
    HLSL fileName.hlsl: the Custom Function file.
    C# scriptName.cs: what the script sets up or drives.
    Compute shaderName.compute: only if the work suits compute.
    1. Create the graph: in the Project window, Create > Shader Graph > HDRP > Lit Shader Graph. Open it and check the Graph Inspector > Graph Settings.
    2. Save Example.hlsl. In the graph, add a Custom Function node. Set Type to File, Source to Example.hlsl and Name to Example (without the _float suffix). Add the inputs In (Float) and the outputs Out (Float), in that order and with those types: they must match the function's parameters.
    3. Describe each further step as one action with its result.
