    Fabric and Folds in Real Time

    Where folds come from, and the three ways games make them: baked into normal maps, faded in by stretch or joint angles, and simulated with particles and constraints. Includes a live cloth simulation.

    Builds on Vectors and Textures. Engine notes cover Unity HDRP, Unity URP and Unreal.

    Where folds come from

    Fabric barely stretches, but it bends with almost no effort. When a sleeve is pushed together, the extra length has to go somewhere, and the only way out is sideways: the cloth buckles into . For gentle, wave-like folds the geometry is simple. If the cloth is compressed by a fraction c and folds with wavelength λ, the folds must rise and fall by about A:

    The wavelength is a property of the fabric. It grows with bending stiffness: silk and jersey make many small folds, denim, leather and wool coats a few large ones. That is why a fold pattern sculpted for one fabric looks wrong on another, and why the rest of this unit has two tools: folds stored in textures for the small ones and simulation for the large ones.

    Folds in the normal map

    Most folds you see on game characters are not geometry. They are sculpted on a high-resolution mesh, baked into a normal map and rendered on a low-poly mesh. A garment usually has two normal maps: the folds, unique to the garment, and a tiling weave or detail map. Combining the two normals is less obvious than it looks. In 2D a normal is just a tilt angle, and the correct result tilts the detail by the base's tilt: the angles add. Compare the common blends:

    Averaging two normals (linear) halves the detail. UDN keeps the base's height and adds the slopes, which flattens on steep folds. Whiteout is close at small angles. Reoriented normal mapping (RNM) rotates the detail normal onto the base normal and is exact, for one extra dot product:

    // Reoriented normal mapping (Barré-Brisebois and Hill). Inputs straight from the textures, in 0..1.
float3 BlendRNM(float3 baseTex, float3 detailTex)
{
    float3 t = baseTex   * float3( 2,  2, 2) + float3(-1, -1,  0);
    float3 u = detailTex * float3(-2, -2, 2) + float3( 1,  1, -1);
    return normalize(t * dot(t, u) / t.z - u);
}

    Shader Graph's Normal Blend node has two modes: Default (whiteout) and Reoriented (RNM). The Lit shader's Detail Map adds a tiling detail normal on top of the main one.

    The same Normal Blend node with Reoriented mode. URP Lit has Detail Inputs (a detail normal map with its own tiling) for the weave.

    Use the BlendAngleCorrectedNormals material function, which implements RNM. Make sure both textures use the Normalmap compression setting.

    Wrinkles from stretch and squash

    Baked folds never move. To make wrinkles appear only when the cloth is pushed together, compare the current length of the mesh edges with their rest length. Each vertex stores its rest edge lengths (or the mesh is compared with its bind pose), and the ratio becomes two masks: one for compression, which fades in a , and one for stretch, which flattens the folds and can show pulling lines:

    // per vertex, after skinning: ratio of current to rest edge length, averaged over the vertex's edges
float squash  = saturate((1 - stretchRatio) * sensitivity);
float stretch = saturate((stretchRatio - 1) * sensitivity);
// in the pixel shader: fade the wrinkle normal in, then add the weave on top
float3 folds = lerp(float3(0, 0, 1), wrinkleNormal, squash);
float3 n     = BlendRNM(folds, weaveNormal);

    Lerping toward the flat normal (0, 0, 1) and normalizing is a cheap way to scale a normal map's strength. The sensitivity is tuned per garment: about 3 to 5 makes a 20 to 30 % squash give full wrinkles.

    Wrinkles driven by joints

    The cheapest dynamic wrinkles need no mesh comparison at all. The folds inside an elbow, behind a knee or across a stomach always appear at the same joint angles. Read the angle from the skeleton (on the CPU, or from an animation curve), turn it into a weight with a smoothstep, and send it to the material:

    A single wrinkle texture can hold folds for several joints. A mask texture with one region per joint (elbow in red, shoulder in green, and so on) limits each weight to its own area: squash = dot(mask, weights). Facial wrinkle maps on high-end characters work the same way, with the weights driven by expressions instead of joint angles.

    Simulating cloth: particles and sticks

    Large folds that swing, like a cape, a skirt or a curtain, need simulation. Almost every real-time cloth solver works the same way. The cloth is a grid of particles. Each particle remembers where it was last frame, and its velocity is simply the difference (Verlet integration, popularised for games by Thomas Jakobsen):

    Damping as written depends on the step rate: the same value loses more speed at 120 Hz than at 30 Hz. Solvers either run at a fixed step or scale the damping with Δt. After moving the particles, the solver pulls neighbours back to their rest distance: those are the . Structural constraints connect direct neighbours, shear constraints the diagonals, and bending constraints particles two apart. Try it:

    Bring the pins together and the cloth falls into vertical drape folds by itself. Switch to Stretch and squash: the blue areas are where a wrinkle map from the previous chapters would fade in. With few iterations the cloth stretches like rubber, which leads to the next chapter.

    Stiffness, iterations and cost

    One constraint step moves both particles a fraction s (the stiffness) of the way back to the rest distance. But each fix disturbs the neighbours, so the solver repeats the whole pass several times per frame. This is . After n passes, a single constraint has closed 1 − (1 − s)ⁿ of its error, so stiffness depends on the iteration count:

    Müller's fix is to use the per-iteration value on the right, so a material looks the same at any iteration count. The newer XPBD replaces stiffness with a physical compliance that is also independent of the time step. In practice, a long cloth needs many iterations, because a correction travels only one particle per pass, or substeps (several small time steps per frame), which converge faster.     That is why production cloth runs on a coarse simulation mesh of a few hundred to a few thousand particles, and the detailed render mesh is skinned to it. Parts that hug the body (a shirt's shoulders) are not simulated at all: each vertex gets a painted max distance it may move away from its skinned position, zero where the cloth is sewn tight. Baked and joint-driven wrinkles add the small folds on top.

    The Cloth component works with a Skinned Mesh Renderer in every pipeline. Paint Max Distance per vertex, set Stretching and Bending Stiffness, and add sphere and capsule colliders for the body. It runs on the CPU, so keep the simulated mesh coarse.

    Same Cloth component as in HDRP. On mobile, prefer joint-driven wrinkles and a few bones driven by spring scripts for capes and hair over full simulation.

    Chaos Cloth: create clothing data on a section of a Skeletal Mesh, paint Max Distance and backstop weights, and tune the cloth config (stiffness, iterations, substeps). Unreal 5 also has a Panel Cloth editor built on Dataflow for more control.

    Build it in Unity HDRP

    Four techniques, four setups: blended fold normals in Shader Graph, joint-driven wrinkles from a C# script, tension wrinkles measured per vertex by a compute shader on the skinned mesh, and a GPU cloth simulation that writes straight into a mesh. The last two are the compute-shader route this unit's lab simulates on the CPU. Written for Unity 6 with HDRP 17; Unity 2022 LTS works the same apart from a few renamed menu entries.

    Compute shaderTension.compute (stretch per vertex), ClothSim.compute (Verlet + Jacobi).

    Engine settingsUnity's Cloth component for CPU simulation.
    1. Baked folds: sample the fold normal map and the weave (Sample Texture 2D, Type Normal), combine with Normal Blend, Mode Reoriented, into Normal (Tangent Space).
    2. Joint-driven wrinkles: add an exposed Vector 4 property _WrinkleWeights and a wrinkle mask texture (one joint per channel). squash = Dot Product(mask, _WrinkleWeights); fade the wrinkle normal in with WrinkleNormal from Wrinkles.hlsl. Add JointWrinkles.cs, assign the renderer and, per joint, the three transforms (for an elbow: shoulder, elbow, wrist) and the start and full angles.
    3. Tension wrinkles: create Tension.compute, add TensionWrinkles.cs to the object with the Skinned Mesh Renderer (GPU skinning on, the default in HDRP). In the graph's vertex context add a Custom Interpolator (Vector 2, named Tension). In the vertex context, add a Custom Function node. Set Type to File, Source to Wrinkles.hlsl and Name to TensionFromBuffer (without the _float suffix). Add the inputs VertexID (Float) and the outputs Tension (Vector 2), in that order and with those types: they must match the function's parameters. Feed VertexID from a Vertex ID node and connect the output to the interpolator. In the fragment stage, its x is squash and y is stretch.
    4. GPU cloth: create ClothSim.compute, add GpuCloth.cs to an empty GameObject with a MeshFilter and MeshRenderer and a double-sided Lit (or Fabric) material. Press Play: the curtain hangs from pleated pins; lower Pin Spacing for deeper folds.
    5. CPU alternative: Unity's Cloth component on a Skinned Mesh Renderer, with painted Max Distance per vertex (Edit cloth constraints), stretching and bending stiffness and capsule colliders.

// Fade the wrinkle normal in by Squash, then reoriented-normal-map it over the base normal.
// Both normals unpacked, in tangent space.
void WrinkleNormal_float(float3 BaseNormalTS, float3 WrinkleNormalTS, float Squash, out float3 Out)
{
    float3 folds = normalize(lerp(float3(0, 0, 1), WrinkleNormalTS, saturate(Squash)));
    float3 t = BaseNormalTS + float3(0, 0, 1);
    float3 u = folds * float3(-1, -1, 1);
    Out = normalize(t * dot(t, u) / t.z - u);
}

// Turns up to four joint angles into wrinkle weights (one per mask channel).
[ExecuteAlways]
public class JointWrinkles : MonoBehaviour
{
    [System.Serializable]
    public struct Joint
    {
        public Transform a, joint, b;            // e.g. shoulder, elbow, wrist
        public float startAngle, fullAngle;      // degrees of bend: wrinkles start, wrinkles complete
    }

    public Renderer target;
    public Joint[] joints = new Joint[4];         // R, G, B, A of the wrinkle mask
    MaterialPropertyBlock block;
    static readonly int WeightsId = Shader.PropertyToID("_WrinkleWeights");

    void LateUpdate()
    {
        if (target == null) return;
        Vector4 w = Vector4.zero;
        for (int i = 0; i < Mathf.Min(4, joints.Length); i++)
        {
            Joint j = joints[i];
            if (j.a == null || j.joint == null || j.b == null) continue;
            // bend = 180 - the angle at the joint: 0 when straight
            float bend = 180f - Vector3.Angle(j.a.position - j.joint.position, j.b.position - j.joint.position);
            float x = Mathf.Clamp01((bend - j.startAngle) / Mathf.Max(j.fullAngle - j.startAngle, 0.001f));
            w[i] = x * x * (3f - 2f * x);         // smoothstep
        }
        block ??= new MaterialPropertyBlock();
        target.GetPropertyBlock(block);
        block.SetVector(WeightsId, w);
        target.SetPropertyBlock(block);
    }
}

// Measures squash and stretch per vertex of a skinned mesh on the GPU, every frame.
// Rest lengths come from the bind pose; keep the rig at scale 1 or adjust the sensitivity.
[RequireComponent(typeof(SkinnedMeshRenderer))]
public class TensionWrinkles : MonoBehaviour
{
    public ComputeShader shader;
    public float sensitivity = 4f;

    SkinnedMeshRenderer smr;
    GraphicsBuffer edgeStart, edgeOther, edgeRest, tension;
    MaterialPropertyBlock block;
    int kernel = -1, vertexCount;
    static readonly int TensionId = Shader.PropertyToID("_Tension");

    void OnEnable()
    {
        smr = GetComponent<SkinnedMeshRenderer>();
        smr.vertexBufferTarget |= GraphicsBuffer.Target.Raw;     // lets compute read the skinned vertices
        Mesh mesh = smr.sharedMesh;
        Vector3[] v = mesh.vertices;
        int[] t = mesh.triangles;
        vertexCount = v.Length;

        // neighbours of every vertex, stored as one flat list plus a start index per vertex
        var nb = new List<int>[vertexCount];
        for (int i = 0; i < vertexCount; i++) nb[i] = new List<int>(8);
        void Link(int a, int b) { if (!nb[a].Contains(b)) nb[a].Add(b); if (!nb[b].Contains(a)) nb[b].Add(a); }
        for (int i = 0; i < t.Length; i += 3) { Link(t[i], t[i + 1]); Link(t[i + 1], t[i + 2]); Link(t[i + 2], t[i]); }

        var start = new int[vertexCount + 1];
        var other = new List<int>();
        var rest = new List<float>();
        for (int i = 0; i < vertexCount; i++)
        {
            start[i] = other.Count;
            foreach (int j in nb[i]) { other.Add(j); rest.Add(Vector3.Distance(v[i], v[j])); }
        }
        start[vertexCount] = other.Count;

        edgeStart = new GraphicsBuffer(GraphicsBuffer.Target.Structured, start.Length, sizeof(int));
        edgeOther = new GraphicsBuffer(GraphicsBuffer.Target.Structured, Mathf.Max(other.Count, 1), sizeof(int));
        edgeRest = new GraphicsBuffer(GraphicsBuffer.Target.Structured, Mathf.Max(rest.Count, 1), sizeof(float));
        tension = new GraphicsBuffer(GraphicsBuffer.Target.Structured, vertexCount, sizeof(float) * 2);
        edgeStart.SetData(start);
        edgeOther.SetData(other);
        edgeRest.SetData(rest);
        block = new MaterialPropertyBlock();
    }

    void LateUpdate()
    {
        if (shader == null) return;
        if (kernel < 0) kernel = shader.FindKernel("Tension");
        using (GraphicsBuffer vb = smr.GetVertexBuffer())    // this frame's skinned vertices; must be disposed
        {
            if (vb == null) return;                          // not skinned yet (first frame, or off screen)
            shader.SetBuffer(kernel, "_Vertices", vb);
            shader.SetInt("_Stride", vb.stride);
            shader.SetInt("_VertexCount", vertexCount);
            shader.SetFloat("_Sensitivity", sensitivity);
            shader.SetBuffer(kernel, "_EdgeStart", edgeStart);
            shader.SetBuffer(kernel, "_EdgeOther", edgeOther);
            shader.SetBuffer(kernel, "_EdgeRest", edgeRest);
            shader.SetBuffer(kernel, "_Tension", tension);
            shader.Dispatch(kernel, Mathf.CeilToInt(vertexCount / 64f), 1, 1);
        }
        smr.GetPropertyBlock(block);
        block.SetBuffer(TensionId, tension);
        smr.SetPropertyBlock(block);
    }

    void OnDisable()
    {
        edgeStart?.Release(); edgeOther?.Release(); edgeRest?.Release(); tension?.Release();
        edgeStart = edgeOther = edgeRest = tension = null;
    }
}
    #pragma kernel Tension

ByteAddressBuffer _Vertices;          // skinned vertices; the position is the first 12 bytes of each
uint _Stride, _VertexCount;
StructuredBuffer<int>   _EdgeStart;   // neighbours of vertex v: _EdgeOther[_EdgeStart[v] .. _EdgeStart[v + 1]]
StructuredBuffer<int>   _EdgeOther;
StructuredBuffer<float> _EdgeRest;    // rest length of each of those edges
RWStructuredBuffer<float2> _Tension;  // x squash, y stretch
float _Sensitivity;

float3 Position(uint i) { return asfloat(_Vertices.Load3(i * _Stride)); }

[numthreads(64, 1, 1)]
void Tension(uint3 id : SV_DispatchThreadID)
{
    uint v = id.x;
    if (v >= _VertexCount) return;
    float3 p = Position(v);
    int s = _EdgeStart[v], e = _EdgeStart[v + 1];
    float ratio = 0;
    for (int k = s; k < e; k++)
        ratio += length(Position((uint)_EdgeOther[k]) - p) / max(_EdgeRest[k], 1e-6);
    ratio = e > s ? ratio / (e - s) : 1.0;                  // average current / rest length
    _Tension[v] = float2(saturate((1.0 - ratio) * _Sensitivity),    // squash
                         saturate((ratio - 1.0) * _Sensitivity));   // stretch
}

// A curtain simulated on the GPU: Verlet integration, Jacobi constraint passes,
// and a kernel that writes positions and normals straight into the mesh's vertex buffer.
[RequireComponent(typeof(MeshFilter), typeof(MeshRenderer))]
public class GpuCloth : MonoBehaviour
{
    public ComputeShader shader;
    public int resX = 48, resY = 36;
    public float width = 2f;
    [Range(0.25f, 1f)] public float pinSpacing = 0.6f;
    [Range(1, 80)] public int iterations = 30;
    [Range(0f, 1f)] public float stiffness = 1f;
    [Range(0f, 0.1f)] public float damping = 0.01f;
    public Vector3 wind = new Vector3(0f, 0f, 1.5f);   // world space, m/s²

    GraphicsBuffer posA, posB, prev, vertexBuffer;
    Mesh mesh;
    int kIntegrate, kSolve, kWrite;
    float spacing;

    void OnEnable()
    {
        if (shader == null || !SystemInfo.supportsComputeShaders) { enabled = false; return; }
        spacing = width / (resX - 1);
        BuildMesh();
        int n = resX * resY;
        var p = new Vector4[n];
        for (int y = 0; y < resY; y++)
            for (int x = 0; x < resX; x++)
                p[y * resX + x] = new Vector4((x - (resX - 1) * 0.5f) * spacing, -y * spacing, 0f, y == 0 ? 1f : 0f); // w = pinned
        posA = new GraphicsBuffer(GraphicsBuffer.Target.Structured, n, 16);
        posB = new GraphicsBuffer(GraphicsBuffer.Target.Structured, n, 16);
        prev = new GraphicsBuffer(GraphicsBuffer.Target.Structured, n, 16);
        posA.SetData(p); posB.SetData(p); prev.SetData(p);
        kIntegrate = shader.FindKernel("Integrate");
        kSolve = shader.FindKernel("Solve");
        kWrite = shader.FindKernel("WriteMesh");
    }

    void BuildMesh()
    {
        int n = resX * resY;
        mesh = new Mesh { name = "GpuCloth" };
        mesh.vertexBufferTarget |= GraphicsBuffer.Target.Raw;           // compute may write into it
        mesh.SetVertexBufferParams(n,
            new VertexAttributeDescriptor(VertexAttribute.Position, VertexAttributeFormat.Float32, 3),
            new VertexAttributeDescriptor(VertexAttribute.Normal, VertexAttributeFormat.Float32, 3),
            new VertexAttributeDescriptor(VertexAttribute.TexCoord0, VertexAttributeFormat.Float32, 2)); // 32 bytes
        var data = new float[n * 8];
        for (int y = 0; y < resY; y++)
            for (int x = 0; x < resX; x++)
            {
                int i = (y * resX + x) * 8;
                data[i + 5] = 1f;                                        // normal +z until the first frame
                data[i + 6] = x / (resX - 1f);
                data[i + 7] = 1f - y / (resY - 1f);
            }
        mesh.SetVertexBufferData(data, 0, 0, data.Length);

        var idx = new int[(resX - 1) * (resY - 1) * 6];
        int k = 0;
        for (int y = 0; y < resY - 1; y++)
            for (int x = 0; x < resX - 1; x++)
            {
                int a = y * resX + x, b = a + 1, c = a + resX, d = c + 1;
                idx[k++] = a; idx[k++] = b; idx[k++] = c;
                idx[k++] = b; idx[k++] = d; idx[k++] = c;
            }
        mesh.SetIndexBufferParams(idx.Length, IndexFormat.UInt32);
        mesh.SetIndexBufferData(idx, 0, 0, idx.Length);
        mesh.subMeshCount = 1;
        mesh.SetSubMesh(0, new SubMeshDescriptor(0, idx.Length), MeshUpdateFlags.DontRecalculateBounds);
        mesh.bounds = new Bounds(Vector3.down * width * 0.5f, Vector3.one * width * 3f);   // never culled while swinging
        GetComponent<MeshFilter>().sharedMesh = mesh;
        vertexBuffer = mesh.GetVertexBuffer(0);
    }

    void Update()
    {
        int n = resX * resY, groups = Mathf.CeilToInt(n / 64f);
        const float dt = 1f / 60f;                                       // fixed step keeps damping consistent
        Vector3 gust = wind * (0.6f + 0.4f * Mathf.Sin(Time.time * 1.7f));
        Vector3 accel = transform.InverseTransformDirection(Physics.gravity + gust);   // simulate in object space

        shader.SetInts("_Res", resX, resY);
        shader.SetFloat("_Spacing", spacing);
        shader.SetFloat("_PinSpacing", pinSpacing);
        shader.SetFloat("_Damping", damping);
        shader.SetFloat("_Stiffness", stiffness);
        shader.SetFloat("_Dt", dt);
        shader.SetVector("_Accel", accel);

        shader.SetBuffer(kIntegrate, "_Pos", posA);
        shader.SetBuffer(kIntegrate, "_Prev", prev);
        shader.Dispatch(kIntegrate, groups, 1, 1);

        for (int i = 0; i < iterations; i++)
        {
            shader.SetBuffer(kSolve, "_PosIn", posA);
            shader.SetBuffer(kSolve, "_PosOut", posB);
            shader.Dispatch(kSolve, groups, 1, 1);
            (posA, posB) = (posB, posA);                                 // ping-pong
        }

        shader.SetBuffer(kWrite, "_PosIn", posA);
        shader.SetBuffer(kWrite, "_VertexOut", vertexBuffer);
        shader.SetInt("_VertexStride", vertexBuffer.stride);
        shader.Dispatch(kWrite, groups, 1, 1);
    }

    void OnDisable()
    {
        posA?.Release(); posB?.Release(); prev?.Release(); vertexBuffer?.Release();
        posA = posB = prev = vertexBuffer = null;
        if (mesh != null) Destroy(mesh);
    }
}

#pragma kernel Solve

RWStructuredBuffer<float4> _Pos;       // Integrate: xyz position (object space), w = 1 if pinned
RWStructuredBuffer<float4> _Prev;
StructuredBuffer<float4>   _PosIn;     // Solve and WriteMesh read the last pass...
RWStructuredBuffer<float4> _PosOut;    // ...and Solve writes the next one
RWByteAddressBuffer        _VertexOut; // the mesh: position (12 bytes), normal (12), uv (8)

uint2  _Res;
uint   _VertexStride;
float  _Spacing, _PinSpacing, _Damping, _Stiffness, _Dt;
float3 _Accel;

uint Index(int2 c) { return (uint)c.y * _Res.x + (uint)c.x; }

float3 PinPosition(uint x)
{
    float s = _PinSpacing;
    float px = ((float)x - (_Res.x - 1) * 0.5) * _Spacing * s;
    float pz = ((x & 1) ? 0.5 : -0.5) * _Spacing * sqrt(saturate(1.0 - s * s));   // pleats keep neighbours at rest length
    return float3(px, 0, pz);
}

[numthreads(64, 1, 1)]
void Integrate(uint3 id : SV_DispatchThreadID)
{
    uint i = id.x;
    if (i >= _Res.x * _Res.y) return;
    float4 p = _Pos[i];
    if (p.w > 0.5)
    {
        float3 pin = PinPosition(i % _Res.x);
        _Pos[i] = float4(pin, 1); _Prev[i] = float4(pin, 1);
        return;
    }
    float3 x = p.xyz, xp = _Prev[i].xyz;
    _Prev[i] = float4(x, 0);
    _Pos[i] = float4(x + (x - xp) * (1.0 - _Damping) + _Accel * _Dt * _Dt, 0);     // Verlet
}

void Constraint(inout float3 corr, inout float count, float3 p, int2 c, float rest, float k)
{
    if (c.x < 0 || c.y < 0 || c.x >= (int)_Res.x || c.y >= (int)_Res.y) return;
    float3 d = _PosIn[Index(c)].xyz - p;
    float len = length(d);
    if (len < 1e-6) return;
    corr += d * (1.0 - rest / len) * 0.5 * k;    // half the error: the neighbour moves the other half
    count += 1.0;
}

[numthreads(64, 1, 1)]
void Solve(uint3 id : SV_DispatchThreadID)
{
    uint i = id.x;
    if (i >= _Res.x * _Res.y) return;
    float4 p = _PosIn[i];
    if (p.w > 0.5) { _PosOut[i] = p; return; }
    int2 c = int2(i % _Res.x, i / _Res.x);
    float r = _Spacing, rd = _Spacing * 1.41421356, s = _Stiffness;
    float3 corr = 0; float n = 0;
    Constraint(corr, n, p.xyz, c + int2( 1,  0), r,  s);     // structural
    Constraint(corr, n, p.xyz, c + int2(-1,  0), r,  s);
    Constraint(corr, n, p.xyz, c + int2( 0,  1), r,  s);
    Constraint(corr, n, p.xyz, c + int2( 0, -1), r,  s);
    Constraint(corr, n, p.xyz, c + int2( 1,  1), rd, s);     // shear
    Constraint(corr, n, p.xyz, c + int2(-1, -1), rd, s);
    Constraint(corr, n, p.xyz, c + int2( 1, -1), rd, s);
    Constraint(corr, n, p.xyz, c + int2(-1,  1), rd, s);
    Constraint(corr, n, p.xyz, c + int2( 2,  0), 2 * r, 0.15);   // bending
    Constraint(corr, n, p.xyz, c + int2(-2,  0), 2 * r, 0.15);
    Constraint(corr, n, p.xyz, c + int2( 0,  2), 2 * r, 0.15);
    Constraint(corr, n, p.xyz, c + int2( 0, -2), 2 * r, 0.15);
    // Jacobi: every particle reads the previous pass only, so all of them run in parallel.
    // Averaging with over-relaxation (1.5) keeps it stable; it needs more passes than Gauss-Seidel.
    _PosOut[i] = float4(p.xyz + corr * (1.5 / max(n, 1.0)), 0);
}

[numthreads(64, 1, 1)]
void WriteMesh(uint3 id : SV_DispatchThreadID)
{
    uint i = id.x;
    if (i >= _Res.x * _Res.y) return;
    int2 c = int2(i % _Res.x, i / _Res.x), m = int2(_Res) - 1;
    float3 p  = _PosIn[i].xyz;
    float3 dx = _PosIn[Index(int2(min(c.x + 1, m.x), c.y))].xyz - _PosIn[Index(int2(max(c.x - 1, 0), c.y))].xyz;
    float3 dy = _PosIn[Index(int2(c.x, min(c.y + 1, m.y)))].xyz - _PosIn[Index(int2(c.x, max(c.y - 1, 0)))].xyz;
    float3 nrm = normalize(cross(dy, dx));
    uint addr = i * _VertexStride;
    _VertexOut.Store3(addr, asuint(p));
    _VertexOut.Store3(addr + 12, asuint(nrm));
}

    The lab on this page solves constraints one after another (Gauss–Seidel), which converges fast but cannot run in parallel. The compute version uses Jacobi passes, where every particle reads the previous pass; that is why it needs more iterations for the same stiffness, and why GPU solvers often colour the constraint graph into independent batches instead. See Compute Shaders for the dispatch basics.

    All of it works in URP: Normal Blend and custom interpolators exist in URP graphs, and the compute and C# files are pipeline-independent.

    Folds: BlendAngleCorrectedNormals. Joint wrinkles: drive scalar parameters from Anim Curves or the Control Rig into a dynamic material instance, the method MetaHuman uses for its wrinkle maps. Simulation: Chaos Cloth (clothing data on the skeletal mesh, painted Max Distance) or a Niagara-based solver for custom GPU cloth.
