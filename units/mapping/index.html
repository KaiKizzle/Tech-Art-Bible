    Simple Mapping Techniques

    Texturing without hand-made UVs, or adding to them: planar and triplanar projection, detail maps, scrolling and flow maps, matcaps, spherical lookups and projected decals. Short, practical, and used on almost every character.

    Builds on Textures and Spaces. Engine notes cover Unity HDRP, Unity URP and Unreal.

    Planar projection: world position as UV

    A mesh's UVs are painted by hand. A projection computes them in the shader instead, from the position of the pixel. The simplest one drops one axis: viewed from above, the world X and Z coordinates are already a perfect UV. This is how terrain, floors and "world-space" dirt or snow layers are textured, and it never needs unwrapping. Its weakness is surfaces that turn away from the projection axis: the same strip of texture covers more and more surface, so it smears:

    // planar projection from above: one texture unit every 1 / scale metres
float2 uv  = worldPos.xz * scale;
float4 col = tex.Sample(samp, uv);

    On a character, use object space (the position before the model matrix) instead of world space, or the texture slides over the mesh as it walks. Object space still swims on skinned parts, because the vertices move inside the object; for those, bake the projection into a UV channel.

    Triplanar mapping

    Triplanar mapping projects three times, along X, Y and Z, and blends the three samples by how much the surface faces each axis. The weights come from the normal: raise its absolute components to a power k to sharpen the transition, then divide by their sum so they add up to 1:

    Low k gives wide, blurry transitions where two projections double up; high k gives a narrow seam. Something like 4 to 8 is common. The cost is three samples of every texture instead of one:

    Two cheaper variants: sample only the dominant axis (one sample, but a hard seam), or biplanar mapping, which samples the two strongest axes. A blend that skips samples with a weight below a small threshold also helps, since most pixels face one axis clearly.

    Shader Graph has a Triplanar node with a Blend (the k above) and a type of Default or Normal. The Lit shader can also use Planar or Triplanar as its UV Mapping (Base UV Mapping option).

    The same Triplanar node in Shader Graph. Use object-space position and normal for anything that moves.

    The WorldAlignedTexture material function projects a texture triplanar, and WorldAlignedNormal does the same for normal maps. Both take a texture size in world units.

    Triplanar normal maps

    Albedo can be blended as above, but a normal map cannot. Each projection's normal map stores its bumps relative to its own plane, and they have to be turned into world space for the plane they were projected on. Using the sample as if it were already the surface normal points every bump the same way:

    The fix is cheap, because each projection plane lines up with two world axes. Swizzle the tangent-space sample into place, add the surface normal with a whiteout blend (blending normals), and flip the sign on the negative side:

    // whiteout triplanar normals (after Ben Golus). tnX, tnY, tnZ: unpacked tangent-space samples
float3 axisSign = sign(N);
tnX.x *= axisSign.x;  tnY.x *= axisSign.y;  tnZ.x *= -axisSign.z;
tnX = float3(tnX.xy + N.zy, abs(tnX.z) * N.x);
tnY = float3(tnY.xy + N.xz, abs(tnY.z) * N.y);
tnZ = float3(tnZ.xy + N.xy, abs(tnZ.z) * N.z);
float3 worldN = normalize(tnX.zyx * w.x + tnY.xzy * w.y + tnZ.xyz * w.z);

    The UVs must use the matching axes: X projection samples at worldPos.zy, Y at worldPos.xz, Z at worldPos.xy, with their x flipped by the same signs so the back sides are not mirrored. Engine triplanar nodes for normals do this for you.

    Detail maps

    A character's main textures cover the whole body, so each texel is a few millimetres wide (texel density). Pores, fabric weave and fine scratches need far more. A is a small tiling texture repeated many times across the surface and combined with the base. Detail colour is usually stored around mid-grey and combined as an overlay: 0.5 changes nothing, darker values darken and lighter values brighten. Up close it adds the fine grain; farther away it should fade out, before it turns into noise:

    Detail normals are blended over the main normal map with the same blends as fold maps. A mask (often a channel of the mask map) limits the detail to where it belongs: pores on the face, not on the lips; weave on the shirt, not on the buttons.

    The Lit shader's Detail Map packs four channels: desaturated albedo (R), smoothness (B) and the detail normal's X and Y (A and G). 0.5 is neutral for albedo and smoothness. The Detail Mask is the blue channel of the mask map.

    URP Lit has Detail Inputs: a mask, a Detail Base Map (combined like an overlay, 0.5 neutral) and a Detail Normal Map, each with its own tiling.

    Multiply a scaled texture coordinate for the detail texture and combine with the base. The DetailTexturing material function does the colour and normal combination in one node.

    Scrolling and flow maps

    Moving a texture over a surface is a single addition: uv + speed · time. That works for a conveyor belt or a waterfall, where everything moves in one direction. For water running around a rock, lava, or energy flowing along a sword, every point should move in its own direction. A stores that direction in two channels. Simply offsetting by direction × time distorts the texture more and more, so the trick is to reset the offset periodically and hide the reset by blending two copies half a period apart:

    float2 flow  = flowTex.Sample(samp, uv).rg * 2 - 1;   // direction, -1..1
float  t0    = frac(time * speed);
float  t1    = frac(time * speed + 0.5);
float4 a     = tex.Sample(samp, uv - flow * t0 * strength);
float4 b     = tex.Sample(samp, uv - flow * t1 * strength + 0.5);  // offset so the copies differ
float  w     = abs(1 - 2 * t0);                     // 1 when copy a resets, 0 halfway
float4 col   = lerp(a, b, w);

    Each copy is invisible at the moment it jumps back. Flow maps are also how hair and satin store their strand direction: the same two channels, read as a tangent instead of a velocity.

    Matcaps and spherical lookups

    A (material capture) is a picture of a lit sphere. Every direction a surface can face toward the camera appears somewhere on that sphere, so the shader can look up the colour directly with the view-space normal: X and Y, mapped from −1..1 to 0..1. No lights, no BRDF, one texture sample:

    Sculpting programs use matcaps for clay previews, and stylised games use them for metal, toon shading or eyes on mobile. Because the lighting is painted relative to the camera, it turns with the view: fine for a character that is always seen from the front, wrong for a scene with a fixed sun.

    Projected decals

    Wounds, dirt, tattoos and blood are rarely painted into a character's textures. They are : a box placed against the surface, projecting a texture along its forward axis. Deferred and screen-space decals reconstruct the position of every pixel inside the box from the depth buffer, move it into the box's local space and use X and Y as UV. Like any planar projection, they stretch on surfaces that turn away, so they fade out by angle:

    float3 local = mul(worldToDecal, float4(worldPos, 1)).xyz;   // box spans -0.5..0.5
clip(0.5 - abs(local));                                        // outside the box: discard
float2 uv   = local.xy + 0.5;
float  fade = saturate((dot(N, -decalForward) - cosLimit) / (1 - cosLimit));

    Add a Decal Projector with a material using the HDRP/Decal shader or a Decal Shader Graph. Angle Fade is the cos limit above. Decal layers keep a character's decals off the floor and the reverse.

    Enable the Decal Renderer Feature (DBuffer or screen space) in the URP Renderer, then use a URP Decal Projector. Rendering layers limit which objects receive it.

    Use a material with the Deferred Decal material domain on a Decal Actor or a Decal Component attached to the character. Receives Decals on a mesh turns them off for it.

    Build it in Unity HDRP

    Most mappings are a node or two in Shader Graph; the ones that need care are triplanar normals, flow maps and matcaps, which are given as Custom Function files. Decals are a component. Written for Unity 6 with HDRP 17; Unity 2022 LTS works the same apart from a few renamed menu entries.

    1. Planar: Position (Absolute World, or Object for things that move) → Split → combine X and Z → Tiling And Offset → Sample Texture 2D. Absolute World keeps HDRP's camera-relative position from making the texture swim.
    2. Triplanar colour: the Triplanar node does it in one step (Position and Normal inputs, Tile, Blend = the sharpness k). Feed it Absolute World position and world normal.
    3. Triplanar normals: the Triplanar node with Type Normal, or Mapping.hlsl for full control. In the Lit graph, add a Custom Function node. Set Type to File, Source to Mapping.hlsl and Name to TriplanarNormal (without the _float suffix). Add the inputs Tex (Texture2D), SS (SamplerState), PositionAWS (Vector 3), NormalWS (Vector 3), Scale (Float), Sharpness (Float) and the outputs NormalOut (Vector 3), in that order and with those types: they must match the function's parameters. The output is a world-space normal: set Graph Settings > Fragment Normal Space to World.
    4. Detail map: sample the detail texture with UV × tiling, combine colours with Blend (Mode Overlay) and normals with Normal Blend (Reoriented), fade with a Smoothstep of the distance between the Camera node's Position and the pixel's World position.
    5. Flow map: Custom Function FlowMap from the same file (inputs Tex, FlowTex, SS, UV, Time, Speed, Strength; output Color).
    6. Matcap: Custom Function MatcapUV (input world normal) gives the UV to sample the matcap texture in an Unlit graph.
    7. Decals: GameObject > Rendering > HDRP Decal Projector (or add the Decal Projector component). Its material uses the HDRP/Decal shader or a graph from Create > Shader Graph > HDRP > Decal Shader Graph. Decals must be enabled in the HDRP asset and the Frame Settings (on by default). DecalOnClick.cs spawns one at a raycast hit.

// ---- Triplanar normal mapping, whiteout blend (after Ben Golus). Output: world-space normal.
void TriplanarNormal_float(UnityTexture2D Tex, UnitySamplerState SS, float3 PositionAWS, float3 NormalWS,
                           float Scale, float Sharpness, out float3 NormalOut)
{
    float3 N = normalize(NormalWS);
    float3 w = pow(abs(N), Sharpness);
    w /= (w.x + w.y + w.z);

    float2 uvX = PositionAWS.zy * Scale, uvY = PositionAWS.xz * Scale, uvZ = PositionAWS.xy * Scale;
    float3 s = sign(N);
    uvX.x *= s.x;  uvY.x *= s.y;  uvZ.x *= -s.z;          // un-mirror the back sides

    float3 tX = UnpackNormalmapRGorAG(SAMPLE_TEXTURE2D(Tex.tex, SS.samplerstate, uvX), 1.0);
    float3 tY = UnpackNormalmapRGorAG(SAMPLE_TEXTURE2D(Tex.tex, SS.samplerstate, uvY), 1.0);
    float3 tZ = UnpackNormalmapRGorAG(SAMPLE_TEXTURE2D(Tex.tex, SS.samplerstate, uvZ), 1.0);
    tX.x *= s.x;  tY.x *= s.y;  tZ.x *= -s.z;

    tX = float3(tX.xy + N.zy, abs(tX.z) * N.x);           // whiteout blend with the surface normal
    tY = float3(tY.xy + N.xz, abs(tY.z) * N.y);
    tZ = float3(tZ.xy + N.xy, abs(tZ.z) * N.z);
    NormalOut = normalize(tX.zyx * w.x + tY.xzy * w.y + tZ.xyz * w.z);
}

// ---- Flow map: two copies half a period apart, blended so each reset is invisible.
void FlowMap_float(UnityTexture2D Tex, UnityTexture2D FlowTex, UnitySamplerState SS, float2 UV,
                   float Time, float Speed, float Strength, out float4 Color)
{
    float2 flow = SAMPLE_TEXTURE2D(FlowTex.tex, SS.samplerstate, UV).rg * 2.0 - 1.0;
    float  t0 = frac(Time * Speed), t1 = frac(Time * Speed + 0.5);
    float4 a = SAMPLE_TEXTURE2D(Tex.tex, SS.samplerstate, UV - flow * t0 * Strength);
    float4 b = SAMPLE_TEXTURE2D(Tex.tex, SS.samplerstate, UV - flow * t1 * Strength + 0.5);
    Color = lerp(a, b, abs(1.0 - 2.0 * t0));
}

// ---- Matcap: view-space normal x and y become the UV.
void MatcapUV_float(float3 NormalWS, out float2 UV)
{
    float3 nV = normalize(TransformWorldToViewDir(NormalWS));
    UV = nV.xy * 0.5 + 0.5;
}

    using UnityEngine;
using UnityEngine.Rendering.HighDefinition;

// Left click in Play mode: places a decal facing the surface that was hit.
public class DecalOnClick : MonoBehaviour
{
    public Material decalMaterial;          // HDRP/Decal or a Decal Shader Graph
    public Vector2 size = new Vector2(0.5f, 0.5f);
    public float depth = 0.3f;              // projection depth of the box
    public float lifetime = 20f;

    void Update()
    {
        if (!Input.GetMouseButtonDown(0) || Camera.main == null) return;
        if (!Physics.Raycast(Camera.main.ScreenPointToRay(Input.mousePosition), out RaycastHit hit)) return;

        var go = new GameObject("Decal");
        // the projector looks along its forward axis: point it into the surface
        go.transform.SetPositionAndRotation(hit.point, Quaternion.LookRotation(-hit.normal, Vector3.up));
        go.transform.Rotate(0f, 0f, Random.Range(0f, 360f), Space.Self);
        var d = go.AddComponent<DecalProjector>();
        d.material = decalMaterial;
        d.size = new Vector3(size.x, size.y, depth);
        d.pivot = Vector3.zero;             // centre the box on the hit point
        Destroy(go, lifetime);
    }
}

    DecalOnClick uses the classic Input class; with the Input System package only, read Mouse.current.leftButton.wasPressedThisFrame instead. If the surface normal is parallel to Vector3.up, LookRotation picks an arbitrary roll, which the random rotation hides anyway.

    Same nodes; use World position (no camera-relative offset). Decals need the Decal Renderer Feature on the URP Renderer and the URP Decal Projector (UnityEngine.Rendering.Universal.DecalProjector). In the HLSL file, UnpackNormalmapRGorAG and TransformWorldToViewDir exist in URP too.

    WorldAlignedTexture and WorldAlignedNormal for triplanar, DetailTexturing for detail maps, FlowMaps functions or a Custom node for flow, Transform (World → View) on the normal for matcaps. Decals: a material with Material Domain: Deferred Decal on a Decal Actor, or SpawnDecalAtLocation from Blueprint.
