    Skin Shading

    Skin glows because light travels under it before it comes back out. This unit builds the techniques games use for that, from a one-line wrap to diffusion profiles, pre-integration and light through ears, plus the two-lobe specular on top.

    Builds on PBR BRDF. Engine notes cover Unity HDRP, Unity URP and Unreal.

    Subsurface scattering in skin

    A Lambert surface reflects light from the exact point where it arrives (the diffuse term). Skin does not. Most light enters it, scatters around in the layers underneath, and leaves a few millimetres away. That softens every shadow edge and gives the transition from lit to unlit a warm red band, because red light travels much farther through tissue than green or blue before it is absorbed:

    The numbers here are illustrative, of the order engines use for skin. What matters is the ratio: red reaches several times deeper than blue. Every technique in this unit is a way to spread the lighting sideways by those distances, cheaply.

    Wrap lighting

    The simplest approximation lets the light "wrap" past the point where N·L reaches zero, as if it scattered a little around the curve. Shift the cosine by w and divide by (1 + w) so a surface facing the light stays at the same brightness (Lambert is w = 0):

    Using a larger w for red than for blue gives the warm terminator. Wrap lighting is a single line and runs on any platform, which makes it the usual choice for mobile, stylised characters and URP. It ignores the size of the object, though: the same w softens a nose and a forehead equally, which the next chapters fix.

    Diffusion profile

    Shine a thin laser into skin and the glow around the entry point fades with distance. That falloff is the R(r). For human skin it is well described by a sum of a few Gaussians of different widths, one weight per colour channel (the fit from NVIDIA's skin research). A wide red Gaussian is what carries red light far:

    All skin techniques use some form of this profile: blur the diffuse lighting by R. The engines expose it as a scattering distance per colour (HDRP) or a subsurface profile asset (Unreal), from which they build the kernel.

    Screen-space subsurface scattering

    The most common real-time method renders the diffuse lighting of skin into its own buffer (a render target), then blurs it with the profile as a kernel, in screen space. The kernel must cover the same number of millimetres at every distance, so its size in pixels shrinks as the face moves away:

    Explained once, used here

    Pixels per metre on screen: screenHeight / (2 · d · tan(fov/2)); halve the distance and a millimetre covers twice the pixels.

    The blur also reads the depth buffer and skips samples that lie on a different surface, otherwise the face would bleed into the background. Specular light is kept out of the blur: it reflects at the surface and stays sharp.

    Set the material type to Subsurface Scattering and assign a Diffusion Profile asset. The profile's Scattering Distance colour and World Scale are the r of this chapter; up to 15 profiles are active per frame, listed in the HDRP global settings.

    URP has no screen-space SSS. Use wrap lighting or the pre-integrated method of the next chapter in Shader Graph, plus the transmission trick for ears.

    Use the Subsurface Profile shading model and a Subsurface Profile asset (scatter radius, falloff colour, dual specular parameters). The screen-space pass is controlled with r.SSS.* settings.

    Pre-integrated skin

    A cheaper method avoids the extra pass. On a curved surface, the scattered light around a point comes from neighbours that face the light at slightly different angles. If the surface is a sphere of radius r, that blur can be computed once, for every N·L and every radius, and stored in a small lookup texture. The shader then reads it with N·L and the local 1/r (from the change of the normal between pixels, or a baked curvature map):

    With the profile as measured, the effect is limited to very small radii: nostril rims, ear edges, fine wrinkles. Productions usually widen the profile (the scale slider) so that noses, lips and eyelids also get a soft red terminator, while cheeks and forehead stay close to Lambert. The lookup texture is computed exactly as the widget does it, once, offline.

    Transmission

    Backlit ears and nostrils glow red because light passes all the way through thin tissue. Shaders model it separately from the surface scattering: a stores how thick the object is at each texel (baked by casting rays inward), and the light that makes it through falls off exponentially with thickness, per colour:

    Explained once, used here

    Beer–Lambert: T = e^(−thickness / ℓ) per channel; red has the longest ℓ in skin, so it gets through.

    Open the full explanation

    The light used for transmission comes from behind, so the shader uses max(0, −N·L) (often wrapped as well). HDRP can also take the thickness from the shadow map instead of a texture, which handles animated characters better.

    Dual-lobe specular

    The surface of skin is covered in a thin oily layer over a rougher base, so its highlight is a sharp, faint lobe on top of a broad one. Engines model it as two GGX lobes with different roughness, mixed. The reflectance at normal incidence is low, F0 ≈ 0.028 (refractive index about 1.4), and a cavity map darkens specular in pores and wrinkles:

    Pore detail lives in a tiling micro-normal map blended over the main normal map (blending normals), faded with distance like any detail map.

    Build it in Unity HDRP

    HDRP has screen-space subsurface scattering built in: a Diffusion Profile asset and a material type. The files add what HDRP does not ship: a compute shader that bakes the pre-integrated skin lookup texture from this unit's profile, and the function that uses it, for URP, mobile or stylised characters. Written for Unity 6 with HDRP 17; Unity 2022 LTS works the same apart from a few renamed menu entries.

    1. Profile: Create > Rendering > HDRP Diffusion Profile. Scattering Distance is the per-colour reach of the diffusion profile (reddish, around 1–2 mm × the multiplier); World Scale is metres per unit; the Transmission section sets the tint and thickness remap for ears.
    2. Register it: Project Settings > Graphics > HDRP Global Settings > Diffusion Profile List (or a Diffusion Profile List override in a Volume). A profile that is not listed renders as plain Lit.
    3. Create the graph: in the Project window, Create > Shader Graph > HDRP > Lit Shader Graph. Open it and check the Graph Inspector > Graph Settings and set Material Type to Subsurface Scattering, with Transmission ticked.
    4. Blocks: Diffusion Profile (a Diffusion Profile property), Subsurface Mask (1 for skin, 0 for lips, nails or eyebrows), Thickness (the thickness map, sRGB off). The screen-space blur of this chapter then runs automatically.
    5. Two specular lobes: use a StackLit graph (Create > Shader Graph > HDRP > StackLit Shader Graph), enable Dual Specular Lobe and set the two smoothness values and the lobe mix. A cavity map goes into Specular Occlusion (Lit: Specular Occlusion Mode Custom).
    6. Pre-integrated alternative: create the compute shader SkinLUT, put SkinLUTBaker.cs in an Editor folder and run Tools > Atlas > Bake Skin LUT. It saves Assets/SkinLUT.png (sRGB off, clamp). In an Unlit (or URP) graph, add a Custom Function node. Set Type to File, Source to PreintegratedSkin.hlsl and Name to PreintegratedSkin (without the _float suffix). Add the inputs LUT (Texture2D), SS (SamplerState), NormalWS (Vector 3), PositionWS (Vector 3), LightDir (Vector 3), CurvatureScale (Float) and the outputs Diffuse (Vector 3), Curvature (Float), in that order and with those types: they must match the function's parameters.
    #pragma kernel Bake
#define PI_ 3.14159265

// x: N.L from -1 to 1. y: curvature 1/r from 0 to _MaxCurvature (1/mm).
// Each texel integrates the diffusion profile around a circle of radius r.
RWTexture2D<float4> _LUT;
uint2 _Size;
float _MaxCurvature;      // 1/mm at the top row, e.g. 0.5 (r = 2 mm)
float _ProfileScale;      // widens the measured profile (1 = as measured)

static const float  VAR[6] = { 0.0064, 0.0484, 0.187, 0.567, 1.99, 7.41 };   // mm^2 (d'Eon and Luebke)
static const float3 W[6]   = { float3(0.233, 0.455, 0.649), float3(0.100, 0.336, 0.344), float3(0.118, 0.198, 0.0),
                               float3(0.113, 0.007, 0.007), float3(0.358, 0.004, 0.0),   float3(0.078, 0.0, 0.0) };

float3 Profile(float d)   // d in mm
{
    float3 r = 0;
    [unroll] for (int i = 0; i < 6; i++) { float v = VAR[i] * _ProfileScale * _ProfileScale; r += W[i] * exp(-d * d / (2 * v)) / (2 * PI_ * v); }
    return r;
}

[numthreads(8, 8, 1)]
void Bake(uint3 id : SV_DispatchThreadID)
{
    if (any(id.xy >= _Size)) return;
    float2 uv = (id.xy + 0.5) / _Size;
    float NdotL = uv.x * 2 - 1;
    float theta = acos(NdotL);
    float curv = max(uv.y * _MaxCurvature, 1e-4);
    float radius = 1.0 / curv;                       // mm

    float3 num = 0, den = 0;
    const int N = 256;
    for (int i = 0; i < N; i++)
    {
        float x = -PI_ + (i + 0.5) * (2 * PI_ / N);  // angle around the circle
        float3 p = Profile(abs(2 * radius * sin(x * 0.5)));
        num += saturate(cos(theta + x)) * p;
        den += p;
    }
    _LUT[id.xy] = float4(num / den, 1);
}

using System.IO;
using UnityEditor;
using UnityEngine;

// Bakes the pre-integrated skin LUT with SkinLUT.compute and saves it as Assets/SkinLUT.png.
public static class SkinLUTBaker
{
    [MenuItem("Tools/Atlas/Bake Skin LUT")]
    static void Bake()
    {
        string[] g = AssetDatabase.FindAssets("SkinLUT t:ComputeShader");
        if (g.Length == 0) { Debug.LogError("SkinLUT.compute not found"); return; }
        var cs = AssetDatabase.LoadAssetAtPath<ComputeShader>(AssetDatabase.GUIDToAssetPath(g[0]));

        const int size = 256;
        var rt = new RenderTexture(size, size, 0, RenderTextureFormat.ARGBHalf, RenderTextureReadWrite.Linear) { enableRandomWrite = true };
        rt.Create();
        int k = cs.FindKernel("Bake");
        cs.SetTexture(k, "_LUT", rt);
        cs.SetInts("_Size", size, size);
        cs.SetFloat("_MaxCurvature", 0.5f);    // 1/mm: the top row is a 2 mm radius
        cs.SetFloat("_ProfileScale", 3f);      // wider than measured, as most productions use
        cs.Dispatch(k, size / 8, size / 8, 1);

        var prev = RenderTexture.active;
        RenderTexture.active = rt;
        var tex = new Texture2D(size, size, TextureFormat.RGBA32, false, true);
        tex.ReadPixels(new Rect(0, 0, size, size), 0, 0);
        tex.Apply();
        RenderTexture.active = prev;
        rt.Release();

        const string path = "Assets/SkinLUT.png";
        File.WriteAllBytes(path, tex.EncodeToPNG());
        Object.DestroyImmediate(tex);
        AssetDatabase.ImportAsset(path);
        var ti = (TextureImporter)AssetImporter.GetAtPath(path);
        ti.sRGBTexture = false;
        ti.wrapMode = TextureWrapMode.Clamp;
        ti.mipmapEnabled = false;
        ti.SaveAndReimport();
        Debug.Log("Saved " + path);
    }
}

// Curvature from screen derivatives: how fast the normal turns per metre (1/m).
// A baked curvature map is steadier; this is the no-extra-texture version.
// CurvatureScale converts 1/m to the LUT's 0..1 range: 0.001 / _MaxCurvature (0.5 /mm) = 0.002.
void PreintegratedSkin_float(UnityTexture2D LUT, UnitySamplerState SS, float3 NormalWS, float3 PositionWS,
                             float3 LightDir, float CurvatureScale, out float3 Diffuse, out float Curvature)
{
    float3 N = normalize(NormalWS);
    Curvature = saturate(length(fwidth(N)) / max(length(fwidth(PositionWS)), 1e-6) * CurvatureScale);
    float NdotL = dot(N, normalize(LightDir));
    Diffuse = SAMPLE_TEXTURE2D_LOD(LUT.tex, SS.samplerstate, float2(NdotL * 0.5 + 0.5, Curvature), 0).rgb;
}

    Multiply Diffuse by the albedo and the light colour, and add specular separately: the LUT replaces only the diffuse N·L.

    URP has no screen-space SSS. Use the pre-integrated LUT above, or wrap lighting with a per-channel wrap (the cheapest trick), plus the thickness-based transmission term, in a Custom Function with GetMainLight().

    Shading Model: Subsurface Profile with a Subsurface Profile asset (scatter radius, falloff colour, transmission, dual specular roughness and mix). Preintegrated Skin is a separate, cheaper shading model for lower-end targets.
